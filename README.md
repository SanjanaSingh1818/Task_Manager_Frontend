# 🚀 Team Task Manager – Frontend

A modern and responsive frontend for the **Team Task Manager** application built using React.  
This app allows users to manage projects, assign tasks, and track progress with role-based access.

---

## 📌 Features

- 🔐 User Authentication (Signup / Login)
- 👥 Role-Based Access (Admin / Member)
- 📁 Project Management
- 📝 Task Creation & Assignment
- 📊 Task Status Tracking
- 📅 Due Date Management
- ⚡ Responsive UI

---

## 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Fetch API

## ⚙️ Setup Instructions

### 1. Clone the repository
git clone https:[//github.com/your-username/task-manager-frontend.git](https://github.com/SanjanaSingh1818/Task_Manager_Frontend.git)

cd client

---

### 2. Install dependencies
npm install

---

### 3. Create `.env` file
VITE_API_URL=https://your-backend-url.up.railway.app

---

### 4. Run the app
npm run dev

---

## 🌐 API Integration

This frontend connects to the backend API hosted on Railway.

Example:

- Auth → `/api/auth`
- Projects → `/api/projects`
- Tasks → `/api/tasks`
